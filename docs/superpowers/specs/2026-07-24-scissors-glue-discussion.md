# 剪刀/胶水 — 设计讨论记录

> 日期：2026-07-24
> 关联 Spec：[2026-07-24-scissors-glue-design.md](./2026-07-24-scissors-glue-design.md)

## 讨论总结

### 剪刀切分（Cut）

- **作用对象**：时间轴，不是时间块。右键某个时间点，以该时刻为界切开当天。
- **精度**：精确到分钟，不吸附。
- **跨线块**：split（同 ID），切口两侧各一半，分别留在当天和移走。
- **多次剪切**：同一天同方向再次剪，新切块合并进已有胶水区。

### 方向

| 方向 | 口诀 | 移走 | 目标日 |
|------|------|------|--------|
| ↓ | "便是明朝" | 切口之后 | 明天 |
| ↑ | "溯与昨宵" | 切口之前 | 昨天 |

### 胶水（Glue）

- 每天一个胶水区（来自前一天）+ 一个胶水区（来自明天）= 最多两个胶水区。
- 胶水块背景色 `#89c3eb`，和普通块一样带 title/tags/note。
- 右键胶水块 → 粘回源日。同一来源的所有块一起粘回。
- `start`/`end` 保持原始值不变，粘回时直接还原。

### 约束

两天之间只能单向：
- 有来自昨天的胶水块 → 不能"溯与昨宵"
- 有来自明天的胶水块 → 不能"便是明朝"
- 但可以同时接收两个方向的胶水块

### DOM 结构

`<main>` 下三个兄弟节点：
```
glue-from-prev  (来自昨天的胶水块)
grid            (今天正常内容)
glue-from-next  (来自明天的胶水块)
```

### 确认弹窗

- 剪刀：`剪刀落处，[hh:mm]，[便是明朝▾]。` 时间可编辑，方向下拉栏类似 More 菜单，入模态栈
- 胶水：`粘回 X月X日？` 简洁确认

### 导出

- 图片导出始终包含胶水块。新增时间范围选择器（全天/自定义），`-`/`+` 前缀区分胶水区
- 文本导出胶水块加 `[来自X/X]` 前缀

### 数据模型

每个块 `_cut: { sourceDate, cutAt }` — start/end 保持不变。

## 逐轮问答

### Q1: 剪刀切的范围
**A**: 不是时间块而是时间轴。右键时间轴上某个时间点。

### Q2: 吸附精度
**A**: 精确到分钟，不吸附。

### Q3: 跨切割线块怎么处理
**A**: 切分为二（同 ID）。切分后小于 10 分钟的片段询问是否保留。

### Q4: 右键交互模型 — 时间轴 vs 时间块
**A**: 时间轴上的右键是剪刀；时间块上的右键保持现有选中切换。

### Q5: 胶水右键范围
**A**: 每天只有一个来自前一天的胶水区和一个来自明天的胶水区。多次剪切自动合并。

纠正：不是"块"而是完整时间轴段。剪在 22:03 意味着今天在 22:03 结束。

### Q6: 胶水块元数据
重新定性：剪下来的不是"块"而是完整时间轴 → 源日的剩余内容自然结束在切口。

### Q20: 胶水右键位置
**纠正**：胶水不是在块上右键，而是在胶水区空白处右键。胶水块本身和普通块一样交互（左键拖拽/创建、右键选中切换）。

### Q21: 多次剪切合并
**纠正**：新切块和已有胶水块合并，同 ID 块合并（min start / max end），cutAt 统一重算（"便是明朝"取 min，"溯与昨宵"取 max）。

### Q22: 胶水块定义
**明确**：胶水块就是带 `_cut` 属性的普通时间块。删除/编辑等行为和普通块保持一致。

### Q23: 跨区创建
**补充**：胶水区和当天之间可以跨区拖拽创建块，粘回时跨区块在边界处 split（同 ID）。

### Q7: 胶水块显示
**A**: 和普通块一样但带标记。背景色 `#89c3eb`。当天 00:00 接在胶水块后面。

### Q8: 存储模型
**A**: 方案 A — 每个块带 `_cut` 标记，自包含回退信息。

### Q9: 剪切线预览
**A**: 需要虚线跟随预览。

### Q10: split 后 ID 是否变化
**A**: 不变。方便粘回后合并。

### Q11: 确认弹窗
最初设计：`剪刀落处，便是明朝\n hh:mm(可调) (确认)(取消)`
后续添加方向下拉："便是明朝" / "溯与昨宵"

### Q12: 同时有前天和明天的胶水块
**A**: 可以同时有。但有了某个方向的胶水块就不能往那个方向切。

### Q13: 被剪天的数据表示
**A**: blocks 数组自然变少，剩余块 start/end 不变，页面高度重新计算。

### Q14: 胶水块位置
**A**: 在 00:00 前面（把 00:00 往下挤）。最终改为 DOM 三个兄弟节点同级的方案——胶水块和 grid 是平级兄弟。

### Q15: start 是否不变
**A**: 不变，保持原始值。

### Q16: DOM 同级方案
**A**: `glue-from-prev` 在 grid 前面，`glue-from-next` 在 grid 后面。三个兄弟节点。导出时自然包含所有 DOM。

### Q17: 约束精确表述
**A**: 两天之间不能双向（他给你 + 你给他 = 不允许）。可以互不相欠，可以你给他，也可以他给你。

### Q18: 剪刀确认框格式
**A**: `剪刀落处，[hh:mm]，[便是明朝▾]。` 内联语句风格。时间可编辑，方向下拉入模态栈。

### Q19: 导出时间范围
**A**: 时间范围选择器新增 `-` / `+` 前缀区分胶水区。自定义模式下起止时间保持开始 ≤ 结束。
